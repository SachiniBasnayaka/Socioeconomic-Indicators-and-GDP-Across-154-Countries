# Socioeconomic Indicators and GDP Per Capita Across Countries

### Statistical Analysis | R Programming | Multiple Linear Regression

## Project Overview

This case study examines the relationships between socioeconomic indicators and GDP per capita across 154 countries. The analysis uses statistical techniques to explore how economic, demographic, and health-related factors are associated with national economic performance.

## Research Objectives

- Examine the relationships between socioeconomic variables and GDP per capita.
- Identify important indicators associated with economic performance.
- Develop and evaluate a multiple linear regression model.
- Interpret statistical findings to understand differences in GDP per capita across countries.

## Dataset

**Source:** [Kaggle – Countries Intermediate Dataset](https://www.kaggle.com/datasets/samira1992/countries-intermediate-dataset)

**Number of Countries:** 154

**Dependent Variable:** GDP per capita

**Independent Variables:**
- Child Mortality Rate
- Exports
- Imports
- Health
- Income
- Inflation Rate
- Life Expectancy
- Total Fertility Rate

## Methodology

The analysis was conducted using R programming and the following statistical methods:

1. Data Cleaning and Preprocessing
2. Exploratory Data Analysis (EDA)
3. Descriptive Statistics and Data Visualization
4. Correlation Analysis
5. Multiple Linear Regression
6. Variable Selection Using Backward Elimination
7. Regression Diagnostics and Model Evaluation

## Key Findings

- Income showed a strong positive relationship with GDP per capita.
- Exports and life expectancy were positively correlated with GDP per capita.
- Child mortality and total fertility rates showed negative relationships with GDP per capita.
- Multiple linear regression was used to construct and compare full and reduced models.
